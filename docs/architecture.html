Backend Rust — Actix-web

Le backend est le point d'entrée de tout le système. Il expose une API REST + WebSocket, gère l'authentification JWT et orchestre les jobs IA via Redis.

Responsabilités

  • Génération et validation des tokens JWT (algorithme EdDSA/Ed25519)
  • Génération du challenge aléatoire de 4 mouvements
  • Création des URLs S3 pré-signées (validité 5 min)
  • Publication des jobs d'analyse sur le canal Redis ia_jobs
  • Souscription aux résultats sur ia_results et retransmission WebSocket
  • Rate limiting : 10 requêtes/heure par utilisateur

AI Worker Python

Le worker Python est un processus long-running qui écoute le canal Redis ia_jobs et traite chaque vidéo séquentiellement.

Pipeline de traitement

  1. Réception du job depuis Redis (user_id, filename, challenge)
  2. Téléchargement de la vidéo depuis MinIO
  3. Vérification anti-deepfake
  4. Extraction frame-par-frame des landmarks faciaux (MediaPipe)
  5. Calcul des angles d'Euler et détection des états de mouvement
  6. Comparaison avec le challenge → score
  7. Publication du résultat sur Redis ia_results

Communication Redis Pub/Sub

Canal ia_jobs — Backend → IA Worker

{
  "user_id": "4643453044896821454",
  "filename": "video_8712.mp4",
  "challenge": "BAS,GAUCHE,BAS,HAUT"
}

Canal ia_results — IA Worker → Backend

{
  "user_id": "4643453044896821454",
  "status": "IA_SUCCESS",           // ou "IA_FAIL", "IA_DEEPFAKE", "IA_ERROR"
  "filename": "video_8712.mp4",
  "movements": [
    { "frame": 120, "direction": "BAS", "raw": { "x": 0.52, "y": 0.35 } },
    { "frame": 210, "direction": "GAUCHE", "raw": { "x": -0.49, "y": 0.05 } }
  ]
}

Stockage MinIO

MinIO est utilisé comme backend de stockage S3-compatible. Les vidéos sont :

  • Uploadées directement par l'app Android via une URL pré-signée (durée 5 min)
  • Stockées dans le bucket pad-bucket
  • Téléchargées par l'IA Worker pour analyse
  • Nommées avec un identifiant unique : video_{random}.mp4
⚠️

Sécurité des vidéos

En production, il est recommandé de supprimer les vidéos après analyse et de configurer une politique de bucket privé. Les URLs pré-signées garantissent un accès limité dans le temps.

Application Android Ring3_App

L'application Android est construite avec Jetpack Compose et CameraX. Elle gère :

  • L'affichage des flèches de challenge à l'utilisateur
  • La capture vidéo via CameraX (caméra frontale)
  • L'upload vers MinIO via l'URL pré-signée
  • La communication WebSocket avec le backend via Ktor
  • L'affichage du résultat (succès / échec)
