Détection de Deepfakes & Anti-Spoofing

Méthodes d'analyse forensique pour détecter les vidéos synthétiques, les rejeux et les manipulations GAN.

⚠️

Première ligne de défense

La détection de deepfake s'exécute avant l'analyse des mouvements. Si une vidéo est identifiée comme synthétique, le traitement s'arrête immédiatement avec le statut IA_DEEPFAKE.

Architecture de la détection

PAD implémente deux modules complémentaires de détection :

  • ia_worker/deepfake_detector.py — Module intégré dans le worker, exécuté à chaque analyse
  • anti-deepfake/ — Module standalone avec des analyses FFT plus approfondies (déployable séparément)

Méthode 1 — Analyse des résidus de bruit

Les GANs et autres systèmes de génération laissent des traces dans les hautes fréquences d'une image. L'analyse des résidus de bruit permet de comparer la texture du visage à celle du fond.

def analyze_noise_residuals(frame, face_region):
    """
    Compare les résidus de bruit entre la région faciale et le fond.
    Les deepfakes montrent une homogénéité anormale du bruit facial.
    """
    # Extraire le résidu de bruit (différence avec version lissée)
    smoothed = cv2.GaussianBlur(frame, (5,5), 0)
    noise_residual = cv2.absdiff(frame, smoothed)

    # Variance du résidu dans la zone faciale vs fond
    face_noise_var = np.var(noise_residual[face_region])
    bg_noise_var   = np.var(noise_residual[~face_region])

    # Ratio anormal → potentiel deepfake
    ratio = face_noise_var / (bg_noise_var + 1e-10)
    return ratio

Méthode 2 — Analyse DCT (Discrete Cosine Transform)

Les réseaux GAN introduisent des artefacts périodiques caractéristiques dans le domaine fréquentiel. La DCT est particulièrement sensible à ces patterns en damier (checkerboard artifacts).

def analyze_dct_coefficients(face_patch):
    """
    Analyse les coefficients DCT du visage.
    Les deepfakes GAN génèrent des artefacts aux fréquences spécifiques
    (souvent liés au stride du réseau de déconvolution).
    """
    gray = cv2.cvtColor(face_patch, cv2.COLOR_BGR2GRAY)
    gray_float = np.float32(gray) / 255.0

    # Appliquer DCT 2D
    dct = cv2.dct(gray_float)

    # Mesurer l'énergie dans les hautes fréquences
    h, w = dct.shape
    high_freq = dct[h//2:, w//2:]
    energy_ratio = np.sum(high_freq**2) / (np.sum(dct**2) + 1e-10)

    return energy_ratio  # Élevé → suspect

Méthode 3 — Analyse du taux de clignement

Les humains clignent des yeux à une fréquence naturelle de 10 à 25 fois par minute. Les vidéos pré-enregistrées ou certains deepfakes présentent des taux anormaux.

BLINK_RATE_MIN = 10   # clignements/min minimum normal
BLINK_RATE_MAX = 25   # clignements/min maximum normal

EAR_THRESHOLD = 0.2   # Eye Aspect Ratio : < 0.2 = œil fermé

def eye_aspect_ratio(eye_landmarks):
    """
    EAR = (||p2-p6|| + ||p3-p5||) / (2 * ||p1-p4||)
    Mesure l'ouverture de l'œil via les 6 landmarks de paupière.
    """
    A = np.linalg.norm(eye_landmarks[1] - eye_landmarks[5])
    B = np.linalg.norm(eye_landmarks[2] - eye_landmarks[4])
    C = np.linalg.norm(eye_landmarks[0] - eye_landmarks[3])
    return (A + B) / (2.0 * C)

def check_blink_rate(blink_count, video_duration_seconds):
    blinks_per_minute = blink_count / (video_duration_seconds / 60)
    return BLINK_RATE_MIN <= blinks_per_minute <= BLINK_RATE_MAX

Méthode 4 — Score de micro-expressions

Les micro-expressions sont de très brèves expressions faciales (50-500ms) qui apparaissent naturellement. Leur absence ou raideur est un indicateur de vidéo synthétique.

def micro_expression_score(landmarks_history):
    """
    Mesure la variabilité naturelle des landmarks sur la durée.
    Trop de régularité = deepfake ou vidéo figée.
    """
    # Calculer la variance temporelle de chaque landmark
    variances = []
    for lm_idx in EXPRESSION_LANDMARKS:
        positions = [frame[lm_idx] for frame in landmarks_history]
        variances.append(np.var(positions))

    mean_variance = np.mean(variances)
    # Score : faible variance = suspect (mouvements trop réguliers)
    return mean_variance

Méthode 5 — Analyse FFT (module standalone)

Le module anti-deepfake/ai_video_detector.py applique une FFT sur chaque frame pour détecter les fréquences périodiques caractéristiques des artefacts GAN.

def detect_gan_frequencies(frame):
    """
    Transformée de Fourier 2D.
    Les GAN laissent des pics d'énergie à des fréquences régulières
    correspondant au stride des couches de déconvolution.
    """
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    f = np.fft.fft2(gray)
    fshift = np.fft.fftshift(f)
    magnitude = 20 * np.log(np.abs(fshift) + 1)

    # Détecter les pics hors DC dans le spectre
    dc_removed = magnitude.copy()
    dc_removed[center] = 0

    peak_ratio = np.max(dc_removed) / np.mean(dc_removed)
    return peak_ratio  # Pic élevé → artefacts GAN possibles

Décision finale — Agrégation des scores

Les différents scores sont combinés pour prendre une décision finale :

def is_deepfake(video_path):
    scores = {}

    for frame in extract_frames(video_path, sample_rate=5):
        scores['noise']   = analyze_noise_residuals(frame)
        scores['dct']     = analyze_dct_coefficients(frame)
        scores['blink']   = check_blink_rate(blinks, duration)
        scores['micro']   = micro_expression_score(landmarks_hist)

    # Verdict : DEEPFAKE si au moins 2 indicateurs déclenchés
    suspicious_count = sum([
        scores['noise'] > NOISE_THRESHOLD,
        scores['dct']   > DCT_THRESHOLD,
        not scores['blink'],
        scores['micro'] < MICRO_THRESHOLD
    ])

    return suspicious_count >= 2   # Majorité = deepfake

Limites et recommandations

🔴

Limites connues

  • Les deepfakes très récents (2024+) utilisant des modèles diffusion peuvent échapper à l'analyse DCT
  • Les vidéos très compressées (H.264 agressif) altèrent les résidus de bruit
  • L'analyse du clignement nécessite une vidéo d'au moins 10 secondes pour être fiable
ℹ️

Pour une sécurité accrue en production

Il est recommandé de coupler PAD avec un modèle deepfake supervisé (ex: EfficientNet fine-tuné sur FaceForensics++) pour les cas à fort enjeu de sécurité.
