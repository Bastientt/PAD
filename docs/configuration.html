Configuration

Toutes les variables d'environnement, les paramètres de l'IA Worker et les options de tuning.

Variables d'environnement — Backend (Rust)

VariableDéfautDescription
REDIS_URL redis://redis:6379 URL de connexion Redis. Format : redis://[user:pass@]host:port
AWS_ACCESS_KEY_ID minioadmin Clé d'accès MinIO/S3
AWS_SECRET_ACCESS_KEY minioadmin Clé secrète MinIO/S3
S3_ENDPOINT http://minio:9000 Endpoint MinIO (à adapter en production)
S3_BUCKET pad-bucket Nom du bucket S3 pour les vidéos
JWT_PRIVATE_KEY_PATH /app/key/private_key.pem Chemin vers la clé privée EdDSA
JWT_PUBLIC_KEY_PATH /app/key/public_key.pem Chemin vers la clé publique EdDSA

Variables d'environnement — AI Worker (Python)

VariableDéfautDescription
REDIS_URL redis://redis:6379 URL de connexion Redis
AWS_ACCESS_KEY_ID minioadmin Clé d'accès MinIO
AWS_SECRET_ACCESS_KEY minioadmin Clé secrète MinIO
S3_ENDPOINT_URL http://minio:9000 Endpoint MinIO pour boto3
RATIO 0.70 Seuil de validation du challenge (0.0–1.0). Plus haut = plus strict.

Paramètres de l'IA Worker

Ces constantes se trouvent en tête de ia_worker/ai_worker.py et peuvent être modifiées directement dans le code.

Exemple docker-compose.yaml annoté

services:
  minio:
    image: minio/minio:latest
    command: server /data --console-address ":9001"
    ports:
      - "9000:9000"   # API S3
      - "9001:9001"   # Console web
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin

  redis:
    image: redis:alpine
    ports:
      - "6379:6379"
    # Ajouter un volume en production :
    # volumes: [redis_data:/data]
    # command: redis-server --requirepass VOTRE_MOT_DE_PASSE

  backend:
    build: ./backend
    ports:
      - "8080:8080"
    environment:
      REDIS_URL: redis://redis:6379
      AWS_ACCESS_KEY_ID: minioadmin
      AWS_SECRET_ACCESS_KEY: minioadmin
    volumes:
      - ./backend/key:/app/key:ro   # Clés JWT en lecture seule
    depends_on:
      - redis
      - minio

  ia_worker:
    build: ./ia_worker
    environment:
      REDIS_URL: redis://redis:6379
      AWS_ACCESS_KEY_ID: minioadmin
      AWS_SECRET_ACCESS_KEY: minioadmin
      S3_ENDPOINT_URL: http://minio:9000
      RATIO: "0.70"     # Tolérance du challenge (configurable !)
    depends_on:
      - redis
      - minio

Configuration de l'application Android

Dans Ring3_App/app/src/main/java/com/padFrontend/MainActivity.kt, modifier les constantes suivantes :

companion object {
    // URL du backend
    const val BACKEND_URL = "http://10.0.2.2:8080"  // Émulateur Android
    // Pour device physique :
    // const val BACKEND_URL = "http://192.168.1.x:8080"

    // Timeout vidéo (ms)
    const val RECORDING_TIMEOUT_MS = 15_000L
}
ℹ️

Adresses réseau Android

10.0.2.2 est l'adresse de l'hôte depuis l'émulateur Android Studio. Pour un device physique, utiliser l'IP LAN de la machine hébergeant le backend.
